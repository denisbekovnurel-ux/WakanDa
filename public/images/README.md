# Фоновые фотографии WakanDa

Добавь свои изображения в эту папку. Формат: `.jpg` или `.webp`, рекомендуется ширина от 1600 px.

- `home-bg.jpg` — фон страницы HOME 홈.
- `daily-bg.jpg` — фон страницы DAILY 매일.
- `oneoff-bg.jpg` — фон страницы ONE-SHOT 단발.

Слот для каждого фото находится справа в верхнем баннере своей страницы. Пока изображения не добавлены, его заменяет тёмный градиент с заметной рамкой.
