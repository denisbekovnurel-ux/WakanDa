# Telegram-бот

Бот отправляет те же напоминания, что и Web Push, плюс тестовое сообщение.
Работает без установки PWA и без разрешения на уведомления.

## Включение

Токен выдаёт [@BotFather](https://t.me/BotFather) командой `/newbot`:

```bash
# server/.env (или корневой .env для Docker)
WAKANDA_TELEGRAM_BOT_TOKEN=123456789:AA...
```

Имя бота сервер получает сам через `getMe`; `WAKANDA_TELEGRAM_BOT_USERNAME`
нужно задавать только если этот запрос недоступен.

## Webhook или long polling

- **Webhook.** Telegram стучится на `/api/telegram/webhook`. Нужен публичный
  HTTPS: задайте `WAKANDA_TELEGRAM_WEBHOOK_URL` (базовый адрес сайта или полный
  URL) и `WAKANDA_TELEGRAM_WEBHOOK_SECRET`. Секрет возвращается в заголовке
  `X-Telegram-Bot-Api-Secret-Token`; без него вебхук не регистрируется — иначе
  кто угодно мог бы прислать код привязки.
- **Long polling.** Если адреса или секрета нет, сервер сам опрашивает
  `getUpdates`. Работает локально, но требует постоянно запущенного процесса.

Если `setWebhook` не удался, сервер пишет в лог и переходит на опрос.

## Привязка аккаунта

В разделе «Инструменты и напоминания» → «Подключить Telegram» → ссылка
`https://t.me/<bot>?start=<код>` → Start привязывает чат. Код живёт 10 минут,
один аккаунт — один чат, повторная привязка отвязывает старый. Меню команд
регистрируется автоматически через `setMyCommands`.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Подключение и главное меню с кнопками |
| `/today` | Сводка: неотмеченные привычки, активные задачи, ближайшее напоминание |
| `/tasks` | Активные разовые задачи с дедлайнами |
| `/reminders` | Активные напоминания; `/reminders 2` удаляет второе по списку |
| `/status` | Привязка, часовой пояс, ежедневные слоты, число напоминаний |
| `/remind` | Создать напоминание |
| `/stop` | Отключить уведомления |
| `/help` | Справка |

Заблокированный пользователь может только `/stop`; остальные команды и
уведомления для него отключены.

## Формат напоминаний

```text
Напомни мне позвонить маме 01.10 в 21:00
/remind 01.10 21:00 позвонить маме
напомни завтра в 9:30 купить хлеб
напомни через 30 минут позвонить маме
напомни в 20:00 выключить плиту
```

Поддерживаются даты `ДД.ММ`, `ДД.ММ.ГГГГ`, `1 октября`, «сегодня», «завтра»,
«послезавтра» и относительные сроки «через 15 минут / час / 2 дня / полчаса».
Время без даты означает ближайшее будущее. Если год не указан и дата прошла,
берётся ближайшая будущая («01.10» в ноябре → 1 октября следующего года).

Каждое напоминание срабатывает один раз: планировщик раз в минуту доставляет его
в Web Push и/или Telegram и помечает отправленным; недоставленное повторяется
в течение суток. Максимум 100 активных напоминаний на аккаунт. Кнопка под
сообщением откладывает его на 10 минут.

## Ежедневные и разовые напоминания

- **Ежедневные.** Один планировщик для Web Push и Telegram сверяет локальное
  время пользователя с тремя слотами из настроек. Защита от дублей — `push_log`.
  Если сервер был выключен, сигнал догоняется в течение 3 часов. Пользователи
  только с Telegram тоже получают напоминания: часовой пояс берётся из чата.
- **Разовые задачи.** В форме есть поле «Напомнить» с датой и временем.
  Планировщик отправляет один раз и не повторяет после закрытия задачи.
  Время можно изменить или убрать прямо в списке.

## API

См. [docs/api.md](api.md): `/api/telegram/status`, `/link`, `/test`, `/webhook`.
Тело вебхука принимается только при корректном секрете. `update_id` сохраняется
в `settings` отдельно для каждого токена — повторный webhook не дублирует
напоминание.
